# Chocolate-Sales-Performance-and-Marketing-Project
This project involves analyzing sales performance and marketing efficiency, observing monthly trends to look for patterns, and which regions are contributing to the sales. 

## Business Questions

This project seeks to answer:

1. How sales performance change over time?
2. What season/quarter did sales best performed?
3. What region/s accounted for major revenue jump?
4. How much revenue is being generated in a typical order?
5. How effective is marketing and does increased marketing corresponds to increase revenue?
6. Which factors affect increase revenue? Quantity of boxes sold or high-value orders?

## Tools used

- MS Excel
- Power Query
- PivotTables
- Data Cleaning
